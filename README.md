# Lucía Gym

App de entrenamiento personal para Lucía, con rutinas y programas pensados para cuidar la zona lumbar L4-L5.

## Instalar en el iPhone

1. Abrir **https://martin10app.github.io/lucia-gym/** en **Safari**.
2. Tocar el botón **Compartir** (⬆️) en la barra inferior.
3. Elegir **Agregar a inicio**.

Queda como una app a pantalla completa, con ícono propio y funciona sin internet después de la primera carga.

## Actualizaciones

Los cambios que se publican en este repositorio llegan solos: al abrir la app con internet, el service worker busca la versión nueva y la aplica. No hay que reinstalar.

## Datos

Todo se guarda en el propio iPhone (localStorage). La sección **Configuración → Respaldo** permite exportar una copia.
